# 개선 계획

## 현재 한계

- BMI 판정 기준은 학습용 예시 기준이며 의료적 판단을 대체하지 않습니다.
- 운동 정보 화면은 앱 자체 데이터가 아니라 외부 검색 결과에 의존합니다.
- 운동 영상 자료는 출처와 사용 권한 정리가 필요합니다.
- 현재 영상 버튼에 연결되지 않은 보조 리소스 등 사용하지 않는 리소스 정리가 필요합니다.
- 운동 계획은 앱을 종료하면 저장되지 않습니다.
- 사용자별 데이터 관리 기능이 아직 없습니다.

## 개선 방향

- 운동 정보를 로컬 데이터로 정리해 앱 내부에서 일관되게 표시할 수 있도록 개선합니다.
- 외부 검색 의존도를 줄이고, 운동 설명과 주의 사항을 앱 내부 데이터로 관리합니다.
- BMI 계산 이력을 저장해 이전 결과를 다시 확인할 수 있도록 합니다.
- 사용자별 운동 목표를 저장하고 계획 화면에서 불러올 수 있도록 합니다.
- `UserDefaults`, SQLite, CoreData 중 앱 규모에 맞는 방식을 선택해 로컬 저장 구조를 추가합니다.
- HealthKit 연동 가능성을 검토해 실제 건강 데이터와 연결할 수 있는 방향을 살펴봅니다.
- 직접 제작 영상 또는 출처와 사용 권한이 명확한 영상 자료를 사용하도록 정리합니다.
- 운동 영상 목록을 배열이나 모델로 관리해 파일명과 화면 표시명을 함께 다룹니다.
- 운동 부위별, 난이도별로 콘텐츠를 분류해 탐색 흐름을 개선합니다.
- 입력 화면, 결과 화면, 계획 화면의 UI/UX를 더 일관된 흐름으로 다듬습니다.

## 포트폴리오 관점의 확장 아이디어

- MVVM 구조를 적용해 화면 로직과 데이터 처리를 분리합니다.
- BMI 계산 로직을 별도 타입으로 분리해 재사용성과 테스트 가능성을 높입니다.
- 운동 데이터 모델을 추가해 운동 이름, 부위, 난이도, 영상 파일명을 구조화합니다.
- 단위 테스트가 가능한 구조로 리팩터링합니다.
- 네트워크 또는 API 기반 운동 데이터 연동 가능성을 검토합니다.
